## 제출 전 반드시 지킬 구분

- 팀 전체 성과와 개인 개발 성과를 동일하게 기술하지 않음.
- '개발에 AI를 활용했다'와 'AI 모델을 직접 학습시켰다'를 혼동하지 않음.
- 파일럿의 정량 수치는 특정 표본·조건에서 관측한 설문값으로만 설명함. 인과효과·일반화 주장 금지.
- 개인 프로토타입에 실제 코드 AI 생성이 포함되므로 '코드 전부 직접 작성' 금지.
- 논문 저자 순위·게재 시기: DOI/KCI 원문과 일치시킴.
- 게임 전체가 실행 가능한 Unity 프로젝트라고 주장하지 않음. 이 저장소는 검토용 선별 코드·문서.

## 별도 증빙 확인이 필요한 항목

- GameMakers 최우수 게임상, SWU SI Award: 상장/공식 명칭·일자 대조.
- 정보처리기사·SQLD: 공식 취득확인서에서 자격 명칭·일자 대조.
- 네 발자국 학술대회 발표 실적: 발표 프로그램·초록집 대조.
